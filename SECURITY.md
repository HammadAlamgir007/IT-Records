# Security Policy

## Supported versions

This repository currently maintains the latest code on the default branch.

## Reporting a vulnerability

If you discover a security vulnerability, please open a private security report through GitHub Security Advisories for this repository.

If private reporting is unavailable, open an issue with minimal details and request a secure contact path before sharing proof-of-concept data.

## Deployment security notes

- Change initial admin credentials immediately after provisioning a new database.
- Restrict access to the SQLite database file and any backups.
- Validate local environment and access controls before using this project in production contexts.
